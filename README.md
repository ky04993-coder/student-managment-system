# Student Management System

A C++ based Student Management System for managing student records.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Automatic Grade Calculation
- Marks Validation
- Duplicate ID Checking
- Save Student Data
- Load Student Data

## Technologies Used

- C++
- Structures
- Functions
- Arrays
- File Handling
- Conditional Statements
- Loops

## How to Run

1. Download or copy `main.cpp`.
2. Open it in a C++ compiler.
3. Compile and run the program.
4. Use the menu to manage student records.

## Project Purpose

This project was created to practice C++ programming, data management, functions, arrays, and file handling.
